# Logotipos de las marcas

Logotipos oficiales sacados de Wikimedia Commons y Wikipedia (en). Son marcas
registradas de sus dueños; la app solo los usa para identificar cada gasolinera.
Antes de guardarlos se revisan (sin scripts ni enlaces externos) y se limpian
(sin metadatos), con `viewBox` para que escalen.
